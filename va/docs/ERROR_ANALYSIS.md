## 三、以 0.40 門檻為例的錯誤類型拆解

0.40 門檻下，OOF 混淆矩陣為 `[[TN=525, FP=27], [FN=148, TP=350]]`
（總計 1,050 筆）：

| 錯誤類型 | 數量 | 佔全部樣本 | 佔該類別樣本 |
|---|---:|---:|---:|
| False Positive（正常被誤判為詐騙） | 27 | 2.57% | 27/552 = 4.89%（＝上表 FPR） |
| False Negative（詐騙被誤判為正常） | 148 | 14.10% | 148/498 = 29.72%（＝ 1－Recall） |

**可讀出的結論**：目前系統在 0.40 門檻下，誤傷正常網站的比例約為 4.89%，
但仍會漏判約 29.72% 的真實詐騙。這是刻意的產品取捨：系統定位是「風險預警」而非
「唯一防線」，並透過白名單、黑名單與硬規則處理明確案例，AI 模型主要協助灰色地帶的風險分級。

## 四、質化錯誤案例（來自目前 `label_review`）

### 類型 A：品牌官方網域／合法網站 + 複雜 URL → False Positive

| 網域 | OOF 機率 | 查證狀態 |
|---|---:|---|

| `disneyplus.com` | 0.7673 | 知名串流品牌官方網域，初步判斷 FP |
| `uniqlo.com` | 0.6805 | 國際知名服飾品牌官方網域，初步判斷 FP |
| `subaru.asia` | 0.6797 | 速霸陸亞洲官方網域，初步判斷 FP |
| `evaair.com` | 0.6721 | 長榮航空官方網域，初步判斷 FP |
| `mercci22.com` | 0.6620 | 合法電商／品牌網站，建議人工確認 |
| `swarovski.com` | 0.6388 | 國際知名精品品牌官方網域，初步判斷 FP |
| `rhinoshield.tw` | 0.6351 | 知名品牌台灣官方網域，初步判斷 FP |
| `oncehuman.game` | 0.5557 | 遊戲官方網域＋重度追蹤參數，初步判斷 FP |

**可能原因**：部分正常品牌網站的 URL 具有較長路徑、多語系資訊或大量廣告追蹤參數，
這些特徵與部分詐騙網址的結構相似，可能使模型提高風險分數。另有部分合法企業網域本身含有
金融或消費相關敏感詞，也可能形成誤判訊號。

**改善方向**（可納入論文未來工作）：
- 將「已知品牌官方網域」與「廣告追蹤參數」的訊號分離，降低正常廣告流量造成的誤判；
- 持續擴充品牌白名單／灰名單，並評估以正式品牌資料源輔助判斷。

**可能原因**：部分詐騙平台本身的 URL 結構非常乾淨，主要透過 LINE 群組、假投資老師、
假出金紀錄等社交工程手法建立信任，而不是透過 URL 外觀偽裝。這是 URL-only 架構的先天限制，
應誠實列入論文的研究限制，而不是宣稱 URL 特徵可以辨識所有詐騙。

## 五、寫進論文的建議段落

> 本研究進一步對 OOF 預測結果中機率與標籤明顯不一致的樣本進行錯誤分析。結果顯示，系統的
> 誤判主要集中於兩種型態：其一為正常品牌或合法企業網站，但 URL 結構較複雜，包含多語系路徑、
> 廣告追蹤參數或具敏感語意的網域文字，因而容易被模型誤判為較高風險；其二為 URL 外觀簡潔、
> 主要依賴社交工程建立信任的詐騙平台，因 URL 本身缺乏明顯異常結構而可能產生 False Negative。
> 前者反映特徵工程仍可針對品牌訊號與追蹤參數進一步細分；後者則反映本研究以 URL 特徵為核心的
> 架構性限制。因此，本系統將黑名單與使用者回報機制作為 AI 模型之外的補強機制，以降低單一
> URL 分類模型的偵測盲區。
